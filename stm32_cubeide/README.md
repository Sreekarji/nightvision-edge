# STM32N6570-DK CubeIDE Project — NIRDet-Forge

## Requirements
- STM32CubeIDE v2.2.0
- ST Edge AI Core v4.0.1 installed at C:\ST\4.0
- STM32N6570-DK applications tree at C:\ST\4.0\Projects\STM32N6570-DK

The build uses absolute include paths to those locations.
A cloner must have them at the same paths or update the include
paths in Appli/.cproject before building.
